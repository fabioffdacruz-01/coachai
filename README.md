# CoachAI

**Menos tempo organizando. Mais tempo transformando vidas.**

## Sobre o projeto

CoachAI é uma plataforma inteligente para profissionais de Educação Física, desenvolvida para auxiliar na gestão de alunos, treinos, avaliações físicas, evolução e acompanhamento, utilizando Inteligência Artificial para apoiar a tomada de decisões.

## Tecnologias

- Python
- FastAPI
- PostgreSQL
- React
- Docker
